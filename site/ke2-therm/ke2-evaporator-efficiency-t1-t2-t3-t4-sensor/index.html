KE2 Therm KE2 Evaporator Efficiency · T1 / T2 / T3 / T4 SENSOR

Why does my KE2 controller show a T1, T2, T3 or T4 SENSOR alarm?

Short answer: Temperature sensor failed (suction, air, coil, or aux). If your KE2 Therm KE2 Evaporator Efficiency is showing T1 / T2 / T3 / T4 SENSOR, the controller has logged a specific, documented condition. This page covers what it means, what causes it, what you can safely fix yourself, and when — and why — it takes a technician.

What exactly is the machine telling you?

The named temperature sensor is open, shorted, or not connected. In the VARIABLES menu a reading of -87 means open/disconnected and 180+ means shorted. Yellow LED is lit and the system keeps running.

Which machines show this?

The KE2 Evaporator Efficiency (KE2 Evap) from KE2 Therm is an aftermarket and OEM evaporator controller found on walk-in coolers and freezers of nearly any box brand — it's one of the most common retrofit controls in the country, often installed to add demand defrost and remote monitoring to an existing walk-in. If your evaporator has a small KE2 display that scrolls text alarms in plain words (HIGH AIR TEMP, DOOR SWITCH, EXCESS DEFROST) rather than cryptic codes, this is it. A yellow LED means a non-critical alarm with the system still running; a red LED is critical. Practical tip: the VARIABLES menu shows live sensor readings — a temperature of -87 means an unplugged sensor, 180+ means a shorted one.

What causes it?

  • The named sensor open or unplugged — a VARIABLES reading of -87 is the giveaway
  • The named sensor shorted — a reading of 180+ points there
  • A sensor wire damaged, pinched, or iced over inside the box

Can you fix it yourself?

Diagnosis yes, repair no. Staff can read which sensor is named in the scrolling text, pull its VARIABLES value (-87 open, 180+ shorted), and eyeball the wire for damage. The system keeps running meanwhile — yellow LED, not a shutdown.

Step by step — what to try, in order:

  1. Note which sensor is named in the scrolling alarm text
  2. Check the VARIABLES menu reading: -87 = open or unplugged, 180+ = shorted
  3. Look for an obviously damaged, pinched, or iced-over sensor wire inside the box
  4. Record the readings for the service tech
One reset is diagnosis, repeated resets are damage. If the same fault returns after a single reset, the underlying condition is real — stop resetting and deal with the cause.

When do you need a technician — and why?

Confirming the failure means testing sensor resistance against KE2's temperature/ohm table and then replacing the sensor — or the controller if the input itself is bad. That's meter work a technician should do.

When to call: Call a tech to test sensor resistance against KE2's temperature/ohm table and replace the sensor or controller as needed.
