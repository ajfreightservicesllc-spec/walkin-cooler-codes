Norlake Programmable Controller (Carel PCO5+ based walk-in control panel) · ROOM TEMPERATURE SENSOR FAILURE

Why is my Norlake walk-in showing ROOM TEMPERATURE SENSOR FAILURE?

Short answer: Air temperature sensor failed. If your Norlake Programmable Controller (Carel PCO5+ based walk-in control panel) is showing ROOM TEMPERATURE SENSOR FAILURE, the controller has logged a specific, documented condition. This page covers what it means, what causes it, what you can safely fix yourself, and when — and why — it takes a technician.

What exactly is the machine telling you?

The room air sensor has failed. The status line will show "USING PROD SENSOR" if the controller falls back to the product sensor, or "SENSOR FAIL MODE" if all sensors have failed and the unit runs on timed Cool On/Heat On cycles.

Which machines show this?

This is Norlake's programmable walk-in controller — a control panel built on the Carel PCO5+ platform, supplied with Norlake walk-in coolers and freezers and their refrigeration packages. Unlike the tiny code-flashing thermostats on many boxes, this one has a multi-line LCD that spells alarms out in full English — DOOR AJAR ALARM, ROOM TEMP HIGH ALARM, AIR FLOW LOSS — with an ALARM button that silences the buzzer and steps through active alarms. The status line on MENU 1 also tells you when the controller is running on a backup sensor. Practical tip: pressing ALARM after closing a left-open door doesn't just silence the noise — it deliberately delays the air-temperature alarm to give the room time to recover, which is exactly what Norlake intends you to do.

What causes it?

  • The room air sensor has failed outright
  • The controller running on fallback — "USING PROD SENSOR" if the product sensor took over, or "SENSOR FAIL MODE" timed cycling if every sensor is gone

Can you fix it yourself?

No — but staff should check the MENU 1 status line to see which fallback the controller is in, verify box temperature with a separate thermometer, and record both for the tech. Fallback keeps the room alive, not well-controlled.

Step by step — what to try, in order:

  1. Check the MENU 1 status line to see which fallback mode the controller is in
  2. Verify box temperature with a separate thermometer
  3. Record the alarm and status for the service tech
One reset is diagnosis, repeated resets are damage. If the same fault returns after a single reset, the underlying condition is real — stop resetting and deal with the cause.

When do you need a technician — and why?

The room is running on backup control, which holds temperature roughly at best — timed cycling can drift either direction. The sensor needs testing and replacement promptly, before backup control turns into a product problem.

When to call: Call a tech promptly — the room is running on backup control and needs the sensor tested and replaced.
