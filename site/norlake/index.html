Norlake Fault & Error Codes

6 documented codes and fault signals, verified against service manuals, with plain-English fixes.

Norlake is one of the major American walk-in box manufacturers, and its factory control option is a programmable control panel built on Carel hardware that skips code numbers entirely — it scrolls plain-text alarms: DOOR AJAR ALARM, ROOM TEMP HIGH ALARM, AIR FLOW LOSS, ROOM TEMPERATURE SENSOR FAILURE. Read them literally, and use the ALARM button to view and silence while you investigate. The status line is the part most people miss: it reports fallback modes like USING PROD SENSOR or SENSOR FAIL MODE that tell you the panel is running your box on backup logic — cooling continues, but the failed sensor needs a prompt service visit, not a shrug.

Worth knowing: many Norlake (and Kolpak) walk-ins ship with the Dixell controller covered elsewhere on this site instead of the programmable panel — check what your display actually looks like. If it shows two-letter codes like P1 or HA, you want the Dixell pages; if it scrolls sentences, you're in the right place below.
